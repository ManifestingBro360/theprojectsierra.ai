• First project out: Canopy 0.3

Tools for people and AI agents who build software together.

More and more code is written by agents working beside people. {{org}} is a small, open home for the tools that make that work visible, safe and worth shipping. Everything here is free, measured in public, and written to be read.

See the projects Contribute on GitHub

What every project here is held to

Five things we check a project against before it carries this name.

Visibility
You can see what each agent read, changed and relied on.
Security
Controls are enforced by the system, not requested in a prompt.
Performance
Numbers are measured and published, including the ones we lose on.
Quality
Each project ships with its review log and its test report.
Outcome
A tool earns its place by what reaches main, not by activity.
